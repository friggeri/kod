Collecting support information

When filing an issue, please include the Kod version/build, macOS version, workspace trust state, steps to reproduce, and any visible status or error text.

Use Help → Export Support Bundle… to save bounded, redacted diagnostic metadata. Inspect the JSON before choosing to attach it; Kod never uploads it automatically.

For a crash, attach the standard macOS crash report. Kod does not automatically collect or transmit crash reports.

For more details, see the full Support documentation on GitHub.
