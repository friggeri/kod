Kod

Privacy

Kod is a local, strictly read-only macOS code viewer. It never sends workspace content or usage telemetry. Automatic update checks are its only default network request.

  • Source code, file paths, symbols, diagnostics, themes, fonts, search terms, and repository data never leave your Mac.
  • Kod collects no usage telemetry of any kind.
  • Kod uses Sparkle 2.9.6 to check GitHub Releases once per day. GitHub receives ordinary connection metadata, but no workspace content. You can opt out in Settings.
  • Updates are signed and notarized, and Kod asks before downloading or installing them.

For more details, see the full Privacy documentation on GitHub.
