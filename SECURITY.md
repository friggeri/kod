# Security Policy

If you discover a vulnerability or security issue in Kod, please file an issue in our public issue tracker on GitHub.

**WARNING:** Because the issue tracker is public, **do not** include:
- Private source code
- Credentials, tokens, or passwords
- Sensitive exploit details that could be actively used against users before a patch is released

Instead, provide a minimal, safe reproduction case and a high-level description of the security implication.

If the problem cannot be described safely in public, open an issue containing
only a request for maintainer contact and retain the sensitive details until a
private channel is established.
